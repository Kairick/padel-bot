# Padel Batumi Bot

Telegram-бот, который показывает свободные корты для падела в Батуми и даёт ссылку на бронирование.

Клубы: **Padel Port Batumi** (Padel Courts + Park Courts) и **Grand Padel Batumi**.

> Неофициальный проект. Не связан с Reservio и клубами. Данные берутся из публичного API страницы бронирования.

## Как работает

- Бот опрашивает публичный JSON:API Reservio `GET /v2/businesses/{businessId}/availability/booking-slots` по каждому корту параллельно.
- Результаты кэшируются в памяти на `CACHE_TTL_SECONDS` (по умолчанию 60 с). Одинаковые одновременные запросы схлопываются в один.
- «Игровой день» длится с 06:00 до 06:00, поэтому ночные слоты 00:00–01:00 показываются в предыдущем дне.
- Кнопка слота открывает список свободных кортов. Для каждого бот создаёт черновой заказ Reservio с выбранным временем и даёт ссылку сразу на оформление. Ссылки кэшируются на 10 минут отдельно для каждого пользователя, частота нажатий ограничена.
- Бот работает только в личных чатах: ссылку на черновой заказ может открыть любой, кто видит сообщение. В группе бот предлагает написать ему в личку.

Клубы и корты описаны в `venues.yaml`. ID услуг можно получить так:

```bash
uv run python scripts/dump_services.py padel-port-batumi2
```

## Локальный запуск

```bash
cp .env.example .env         # вписать BOT_TOKEN от @BotFather
uv sync
uv run padel-bot
```

Посмотреть слоты без Telegram:

```bash
uv run python scripts/show_slots.py tomorrow e   # m=утро, a=день, e=вечер, w=весь день
```

Тесты и линт:

```bash
uv run pytest
uv run ruff check . && uv run ruff format --check .
```

## Статистика

Бот ведёт обезличенную статистику в SQLite, по умолчанию в файле `data/stats.sqlite3`.

- Вместо Telegram id хранится хеш с секретной солью, по одной строке на пользователя в день. Соль задаётся переменной `STATS_SALT` и в базу не пишется, поэтому по одному файлу базы id не восстановить. Без `STATS_SALT` уникальные пользователи не считаются вовсе: бот пишет ошибку в лог, а `/stats` предупреждает об этом. Счётчики действий работают в любом случае. Соль нельзя менять после запуска, иначе те же люди посчитаются заново.
- Действия считаются счётчиками по дням без привязки к пользователям: открыли бота, смотрели день, обновляли, открыли время (с клубом и часом).
- Команда `/stats` показывает уникальных пользователей за день, 7 и 30 дней, новых за неделю, действия, популярные клубы, часы и языки.
- `/stats` отвечает только пользователям из `ADMIN_IDS`. Пока список пуст, команда подсказывает твой id.

## Деплой на Fly.io

Бот работает через long polling, входящий порт не нужен. База статистики лежит на постоянном томе `/data`.

```bash
fly launch --no-deploy --copy-config   # один раз
fly volumes create padel_data --size 1 --region fra   # один раз, для статистики
fly secrets set BOT_TOKEN=... ADMIN_IDS=... STATS_SALT=$(openssl rand -hex 32)
fly deploy --ha=false
```

Машина должна быть ровно одна. Две машины с одним токеном получат конфликт long polling в Telegram, а том со статистикой подключается только к одной. Если Fly всё же создал вторую, выполни `fly scale count 1`.

Для автодеплоя из GitHub добавь секрет `FLY_API_TOKEN` (`fly tokens create deploy`) и запусти workflow «Deploy to Fly.io».

Альтернатива: любой VPS с Docker.

```bash
docker build -t padel-bot .
docker run -d --restart unless-stopped --env-file .env padel-bot
```
